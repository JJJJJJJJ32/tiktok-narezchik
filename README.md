# Бот-нарезчик Shorts / TikTok

Берёт новые видео с YouTube-каналов **и из TikTok**, режет их на вертикальные клипы
1080×1920, добавляет субтитры, музыку, при желании переводит речь на русский
с озвучкой и вставляет рекламные ролики — а потом загружает всё на Google Drive
и присылает письмо со ссылками.

```
┌──────────────────────────┐
│  видео на всю ширину     │  1080×608, чёрные поля сверху и снизу (как в примере)
│  СУБТИТРЫ внутри видео   │  КАПС, Montserrat Black, чёрная обводка
│  чёрное поле             │
└──────────────────────────┘
```

Кадр можно собрать пятью способами:

| Режим | Что получается |
|---|---|
| `width` | видео на всю ширину, сверху и снизу чёрные поля — как в `пример.mp4` |
| `crop` | видео заполняет весь кадр, лишнее по краям обрезается |
| `folder` | сверху видео, снизу фоновый ролик из `backgrounds/` |
| `blur` | сверху видео, снизу его же размытая копия |
| `black` | сверху видео, снизу чёрный |

## Возможности

- **Несколько ботов = несколько Google-аккаунтов.** У каждого бота своя почта,
  свой Диск, свой файл токена и свои каналы. За один запуск бот проходит по всем
  включённым профилям: первый грузит на свой Диск, второй — на свой.
- **Нарезка по паузам** в речи (C++ модуль или Python-фолбэк), продолжение
  с места остановки после закрытия программы.
- **Субтитры** через `faster-whisper` с пословными таймкодами.
- **Перевод и озвучка.** Речь распознаётся, переводится на русский
  (`translate.googleapis.com`, без ключей) и озвучивается голосом
  `edge-tts` (Дмитрий / Светлана / Дария). Субтитры тоже на русском.
- **Музыка** — случайный трек из `music/` под клип, громкость настраивается.
- **Рекламные вставки** из `banners/`: клип до 2 минут — одна вставка посередине,
  длиннее — каждые N секунд. Во время вставки основное видео и субтитры
  останавливаются. Однотонный (зелёный) фон ролика вырезается.
- **TikTok** — платформа определяется по ссылке, для TikTok свой формат
  скачивания и свой минимум длительности (5 с).
- **Письмо** со ссылками на клипы и общий `report.csv` на Диске.

## Установка на Windows с нуля

### 1. Python 3.10+
Скачайте с [python.org](https://www.python.org/downloads/windows/) и при установке
поставьте галочку **Add python.exe to PATH**. Проверка:

```powershell
python --version
```

### 2. FFmpeg в PATH
```powershell
winget install Gyan.FFmpeg
```
Перезапустите терминал и проверьте:
```powershell
ffmpeg -version
ffprobe -version
```

### 3. Зависимости
```powershell
cd путь\к\проекту
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`faster-whisper` при первом запуске сам скачает модель (`small` ≈ 460 МБ) в кэш.
`edge-tts` нужен только для озвучки, но ставится сразу.

### 4. Компилятор C++ и сборка модуля (необязательно)
Вариант А — MinGW-w64:
```powershell
winget install BrechtSanders.WinLibs.POSIX.UCRT
```
Если winget не сработал — скачайте zip с [winlibs.com](https://winlibs.com/), распакуйте
и добавьте `<папка>\mingw64\bin` в `PATH`.

Затем:
```powershell
python build_cpp.py
```
Появится `cpp/bin/silence_finder.exe`. Если собрать не удалось — бот продолжит
работать на Python-фолбэке. Отключить C++ принудительно: `USE_CPP = False`.

### 5. Шрифт
`fonts/Montserrat-Black.ttf` уже лежит в проекте. Для другого шрифта положите TTF
в `fonts/` и поменяйте `FONT_NAME` и `FONT_FILE` в `config.py`.

### 6. Папки с медиа
- `backgrounds/` — фоновые ролики (нужны только для режима «снизу фон из папки»);
- `music/` — треки `.mp3`, `.m4a`, `.wav`, `.ogg` (случайный на клип);
- `banners/` — рекламные ролики `.mp4`, `.mov`, `.webm`.

Папки можно не создавать заранее: бот просто скажет, что они пусты.

### 7. Google Drive и почта: `credentials.json`

1. Откройте [console.cloud.google.com](https://console.cloud.google.com/), создайте проект.
2. **APIs & Services → Library**: включите **Google Drive API** и **Gmail API**.
3. **APIs & Services → OAuth consent screen**: тип **External**, добавьте себя
   в **Test users**.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**.
   Application type: **Desktop app**.
5. Скачайте JSON, переименуйте в `credentials.json`, положите рядом с `main.py`.
6. Меню → **БОТЫ** → бот → **GOOGLE: ПОЧТА И ДИСК** → **ВОЙТИ В GOOGLE**.
   Браузер откроется, войдите аккаунтом этого бота — появится его файл токена.

Права: `drive.file` (бот видит только созданное им) и `gmail.send`
(только отправка писем, читать переписку бот не может).

**У каждого бота свой аккаунт.** Первому боту достаётся `token.json` и папка
`TikTok Bot`, второму — `token-2.json` и `TikTok Bot 2`, третьему — `token-3.json`
и так далее. Файл ключей `credentials.json` общий: один проект Google на всех.

## Запуск

```powershell
python main.py                    # открывается меню
python main.py --no-menu          # без меню, сразу запуск
python main.py --dry-run          # проверка: без загрузки и без удаления
python main.py --dry-run --channel https://www.youtube.com/@канал
python main.py --channel https://www.tiktok.com/@профиль
```

### Меню

1. **НАЧАТЬ ЗАПУСК** — полный прогон или проверочный (dry-run);
2. **СТАТИСТИКА** — сколько видео и клипов уже сделано;
3. **БОТЫ (N)** — список ботов: выбрать бота или добавить нового (до 10);
4. **ОБЩИЕ НАСТРОЙКИ** — почта, удаление файлов, лимиты, музыка, перевод, реклама;
5. **ПРОВЕРКА СВЯЗИ** — интернет, YouTube, ffmpeg, шрифт, Диск, Gmail, место на диске;
6. **ОТЧЁТ** — что уже загружено.

Внутри бота:

1. **КАНАЛЫ** — ссылки на YouTube-каналы и TikTok-профили;
2. **ФОН И КАДР** — пять режимов кадра + папка фонов;
3. **РАЗМЕР ФОНА, ВИДЕО И РАСПОЛОЖЕНИЕ** — высота видео, длина клипа, размер субтитров;
4. **GOOGLE: ПОЧТА И ДИСК** — вход, файл токена, папка на Диске, адрес почты, проверка;
5. **ВКЛЮЧЁН / ВЫКЛЮЧЕН** — выключенный бот не участвует в запуске;
6. **УДАЛИТЬ**.

Настройки из меню хранятся в `settings.json`, `config.py` остаётся заводским.

Лог пишется в консоль (красиво) и в `bot.log` (для разбора ошибок).

## Что происходит с файлами

- Исходник скачивается в `work/raw/`, клипы собираются в `output/<id>/`.
- Готовые рекламные ролики кэшируются в `work/banners_ready/`.
- После успешной загрузки на Диск **и** отправки письма исходник, клипы и
  временные файлы удаляются (`DELETE_LOCAL_AFTER_UPLOAD = True`).
- Если письмо не ушло — файлы остаются, чтобы ничего не потерять.
- Каждая часть получает 1 попытку + `CLIP_RETRIES = 3` повтора. Если часть так
  и не смонтировалась, бот пропускает её, загружает остальные и пишет
  «пропущено» в отчёт и письмо.

## Продолжение после закрытия

Если закрыть программу посреди работы, следующий запуск продолжит с того же
места. Ход хранится в `work/progress/<id_видео>.json`.

- Уже скачанный исходник не качается заново: файл проверяется через `ffprobe`.
- Уже найденные паузы, распознанный текст и озвучка не считаются заново.
- Смонтированные и целые клипы не перемонтируются; недостающие — только они.
- Уже загруженные на Диск части не загружаются повторно.
- Письмо отправляется один раз.
- Строка в `report.csv` для того же видео заменяется, а не дублируется.
- После завершения видео отмечается в `state.sqlite`, файл прогресса удаляется.

## Как это работает

1. **Скачивание** — `yt-dlp`. Платформа определяется по ссылке: для TikTok
   свой формат и минимум длительности 5 с, для YouTube — `MIN_VIDEO_DURATION`.
   Обработанные видео помнятся в `state.sqlite`. Видео берутся по кругу:
   партия от одного автора, партия от следующего, потом снова к первому.
2. **Поиск пауз** — аудио как PCM 16 кГц mono уходит в `cpp/silence_finder`:
   RMS по окнам 20 мс, порог тишины = 15-й перцентиль энергии × 2.5.
3. **Распознавание** — `faster-whisper`, пословные таймкоды.
4. **Перевод и озвучка** (если включено) — фразы по 4–8 слов переводятся через
   `translate.googleapis.com`, синтезируются в `voice/NN.mp3`, при перерасходе
   времени ускоряются через `atempo` и раскладываются по таймкодам в `voice.wav`.
5. **Кадр** — один проход FFmpeg: `trim → scale → pad/crop → vstack → ass`,
   плюс подмешивание музыки и озвучки одним `amix`.
6. **Реклама** — ролик заранее готовится отдельным коротким проходом
   (вырезание однотонного фона по цвету четырёх углов + чёрная подложка),
   кэшируется, а затем вставляется в общий фильтр через `split` + `concat`:
   сегмент клипа, ролик, следующий сегмент. Длительность клипа растёт на сумму
   вставок.
7. **Загрузка** — `TikTok Bot / <канал> / <видео> / <канал>_<название>_part03of12.mp4`,
   описание с автором, ссылкой, частью X из Y и таймкодами.
8. **Письмо** — на Gmail уходит письмо со ссылками на клипы.

## Если YouTube не открывается

Симптом в логе: `Unable to download API page ... Failed to resolve 'www.youtube.com'`
или `getaddrinfo failed`, при этом остальные сайты работают.
Это DNS-блокировка провайдера. Бот обходит её сам — `USE_DOH_FALLBACK = True`:
домены YouTube и TikTok резолвятся через DNS-over-HTTPS (`dns.google`,
`cloudflare-dns.com`, `dns.adguard-dns.com`).

Если в логе `Connection aborted` или `ConnectionResetError(10054)` — провайдер
режет сам CDN по SNI. Нужен VPN или прокси:
```python
PROXY = "socks5://127.0.0.1:1080"   # или "http://127.0.0.1:8080"
```

Если при скачивании `Sign in to confirm you're not a bot` — экспортируйте
cookies из браузера в `cookies.txt` и укажите `COOKIES_FILE = "cookies.txt"`.

## Если Google Диск обрывает связь

`RemoteDisconnected` или `[WinError 10054]` — Drive закрыл соединение.
Все обращения к Диску повторяются до 4–5 раз с паузами 2–20 с, уже загруженные
клипы не грузятся повторно.

## Если клип не собирается

Симптом: `ffmpeg: код ...` или процесс падает без сообщения.
Чаще всего не хватает оперативной памяти: 1080×1920 с субтитрами, музыкой,
озвучкой и рекламой — тяжёлый фильтр. Что помогает:

- закрыть браузер и другие тяжёлые программы;
- уменьшить `PARALLEL_JOBS` до 1;
- снизить `CRF` не нужно, а `PRESET = "veryfast"` оставить;
- отключить рекламу или музыку, если память совсем в обрез.

Рекламные ролики готовятся отдельным коротким проходом именно поэтому:
вырезание фона внутри общего фильтра раньше роняло ffmpeg на длинных клипах.

## Автотесты

```powershell
python tests/selftest.py             # паузы, нарезка, фон, имена, report.csv
python tests/selftest.py --render    # + Whisper (скачает модель) и сборка клипа
python tests/smoke.py                # письмо, отчёт, фон blur/black (без сети)
python tests/retry.py                # автоповторы Google Диска (без сети)
python tests/layout.py               # вставки рекламы, позиция субтитров, режимы кадра
python tests/worker.py               # настройки из меню доходят до процесса рендера
python tests/render.py               # пробный рендер: клип + музыка + реклама + озвучка
```

`tests/render.py` собирает синтетический клип 640×360 на 24 секунды, кладёт
музыку, рекламу на зелёном фоне и озвучку, а затем проверяет: кадр 1080×1920,
длительность 24 + 4 секунды, звук на месте, чёрные поля сверху и снизу,
зелёный фон рекламы вырезан.

## Допущения и ограничения

- ОС Windows (код кроссплатформенный, но инструкция под Windows).
- Язык речи определяется автоматически (`LANGUAGE = None`).
- Обрезка интро/аутро не делается.
- Клипы собираются без перекрытия: каждый следующий начинается там, где закончился предыдущий.
- Если в клипе нет речи, `.ass` будет пустым — видео всё равно соберётся.
- `BACKGROUND_VOLUME > 0` требует, чтобы у фоновых роликов была звуковая дорожка.
- Длительность клипа может отличаться от заданной на ±`CUT_SEARCH_WINDOW`.
- Перевод и озвучка требуют интернета: `translate.googleapis.com` и Microsoft Edge TTS.
- Реклама вставляется только в клипы длиннее 20 секунд.

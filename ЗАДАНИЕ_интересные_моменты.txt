# ЗАДАНИЕ: интересные моменты из видео — ТОЛЬКО по субтитрам

Ты работаешь над проектом «Бот-нарезчик Shorts/TikTok» (Python, Windows, ffmpeg,
faster-whisper, yt-dlp, Google Drive). Сейчас бот режет видео подряд: ищет паузы
и делает клипы примерно по 45 секунд (CLIP_DURATION), пока видео не закончится.

Нужно добавить режим «интересные моменты»: выбирать из всего видео самые
содержательные фрагменты.

ГЛАВНОЕ ОГРАНИЧЕНИЕ:
Интересные моменты определяются ТОЛЬКО по субтитрам — по распознанному тексту
и его таймкодам. Анализ звука, громкости, смеха, музыки и энергии НЕ делать.
Единственный источник данных для выбора — слова из faster-whisper:
{"word": "...", "start": 1.23, "end": 1.56}.

Задача считается выполненной, когда режим включается в меню, работает на
YouTube и TikTok, не ломает музыку, перевод, озвучку и рекламные вставки,
а при выключении бот ведёт себя точно как раньше.

======================================================================
1. ЧТО СЧИТАТЬ ИНТЕРЕСНЫМ МОМЕНТОМ
======================================================================

Интересный момент — это окно длиной примерно CLIP_DURATION (45 с), в тексте
субтитров которого:

- много живой речи и мало длинных провалов без слов;
- есть «зацепки»: вопросы, числа, деньги, секреты, ошибки, признания,
  эксперименты, неожиданные повороты;
- слышна эмоция в словах: смех, восклицания, сильные формулировки;
- в начале окна есть крючок, который цепляет зрителя;
- это не интро, не заставка и не аутро;
- окна не пересекаются и не идут вплотную друг к другу.

Всё это вычисляется по словам и их таймкодам. Никаких аудиопризнаков.

======================================================================
2. ПАЙПЛАЙН: ЧТО ИЗМЕНИТЬ
======================================================================

Сейчас в main.process_video:

    pcm = cutter.extract_pcm(видео)
    result = cutter.find_cuts(pcm)
    segments = cutter.make_segments(result)

Нужно:

    если HIGHLIGHTS_ENABLED:
        полная расшифровка всего видео ОДИН раз (faster-whisper)
        segments = highlights.pick_segments(слова, длительность)
    иначе:
        pcm = cutter.extract_pcm(видео)
        result = cutter.find_cuts(pcm)
        segments = cutter.make_segments(result)

Важно: расшифровывать видео нужно ОДИН раз на всё видео, а не заново для
каждой части. Сейчас main._prepare_part вызывает
subtitles.transcribe_detail(wav) для каждой части. После внедрения полной
расшифровки части должны брать готовые слова из неё:

    main._prepare_part(..., words=None, language=None)

    если words переданы:
        взять слова, попадающие в [start, end]
        сдвинуть их таймкоды на -start (чтобы часть начиналась с 0)
        НЕ извлекать audio.wav и НЕ вызывать whisper заново
    иначе:
        работает как сейчас

Полную расшифровку сохранять в work/clips/<video_id>/words.json:

    {
      "version": 1,
      "language": "ru",
      "duration": 1234.5,
      "words": [{"word": "...", "start": 1.23, "end": 1.56}, ...]
    }

Если файл уже есть при продолжении после закрытия — читать его, а не
расшифровывать заново. Прогресс (work/progress/<id>.json) уже хранит segments,
поэтому выбранные моменты при возобновлении не пересчитывать.

Субтитры для готовых клипов по-прежнему собираются из этих же слов через
subtitles.group_phrases / subtitles.write_ass — формат .ass не меняется.

======================================================================
3. КАНДИДАТЫ: ГДЕ МОЖЕТ НАЧИНАТЬСЯ КЛИП
======================================================================

Источник границ — паузы между словами в субтитрах:

- пауза = разрыв между end предыдущего слова и start следующего;
- границей окна считать паузу от 0.30 с;
- начало окна — конец паузы (или 0 в самом начале);
- конец окна — начало паузы рядом с (начало + CLIP_DURATION);
- длительность окна: CLIP_DURATION плюс-минус 20 % (для 45 с это 36–54 с);
- если подходящей паузы нет — брать ровно CLIP_DURATION;
- окна не должны выходить за границы видео;
- в окне должно быть минимум 8 слов;
- дубликаты окон с одинаковыми start/end убрать.

Кандидатов должно быть много: начало каждого окна — каждая подходящая пауза,
а не только каждые 45 секунд.

Если видео короче 2 * CLIP_DURATION или слов меньше 20 — кандидатов не строить,
использовать старую нарезку.

======================================================================
4. ОЦЕНКА ОКНА — ТОЛЬКО ТЕКСТ СУБТИТРОВ
======================================================================

Для каждого окна W берутся слова, целиком попадающие в W, и их таймкоды.

4.1. Речь
    speech_ratio = сумма (end-start) слов / длительность W
    words_per_sec = количество слов / длительность W

    Хорошо: speech_ratio 0.55-0.90, words_per_sec 2.0-4.5.
    Плохо: speech_ratio < 0.30 (мало речи) или > 0.95 (тараторит без пауз).

4.2. Паузы внутри окна
    longest_gap = самый длинный разрыв между словами внутри W
    gap_ratio = сумма разрывов длиннее 1.0 с / длительность W

    Штраф, если longest_gap > 1.5 с или gap_ratio > 0.20.

4.3. Слова-триггеры
    Список HIGHLIGHTS_KEYWORDS (нижний регистр, русский + пара английских):
    секрет, ошибк, правд, никогда, впервые, шок, деньги, рубл, доллар,
    миллион, тысяч, бесплатно, главн, самое, почему, зачем, как, что будет,
    нельзя, опасно, жест, срочно, лайфхак, совет, тест, эксперимент,
    проверк, истори, признал, провал, успех, сработал, не сработал,
    обман, развод, скрыва, запрещ, скандал, потерял, нашёл, научил,
    ошибся, предал, влюбил, уволил, разбогател.

    Сравнение: слово очищается от знаков препинания и приводится к нижнему
    регистру; совпадением считать вхождение триггера как подстроки
    (минимум 4 символа), чтобы ловить падежи: «секрет», «секреты»,
    «секретного».

    keyword_score = количество срабатываний на 10 секунд окна.

4.4. Вопросы
    question_score = количество вопросительных слов
    (почему, зачем, как, что, кто, где, когда, сколько, разве, неужели)
    на 10 секунд окна + 0.5 за каждый знак «?», если он есть в тексте.

4.5. Числа и деньги
    number_score = количество чисел, процентов и денежных слов на 10 секунд
    (регулярка по цифрам + слова: процент, тысяч, миллион, рубл, доллар,
    гривен, тенге).

4.6. Эмоция в тексте
    emotion_score = количество эмоциональных слов и смеха на 10 секунд:
    ха, хаха, ахах, хех, смех, аплодисмент, вау, ого, боже, кошмар, жесть,
    класс, супер, обожаю, ненавижу, страшно, больно, счастлив, ужас,
    невероятно, безумно, срочно, наконец, представляешь.

4.7. Крючок в начале
    hook_score — есть ли в первых 5 секундах окна слова:
    представь, представьте, слушай, слушайте, вот, знаете, однажды,
    когда я, самое, главное, никогда, впервые, секрет, признаюсь,
    я не поверил, вы не поверите.

    1.0 — есть, 0.0 — нет.

4.8. Личная история
    self_score = доля слов «я, мне, меня, мной, мой, моя, моё, мои, мы, нас»
    среди всех слов окна. Личные истории обычно цепляют.

4.9. Штрафы
    - первые 20 секунд видео: -0.25 (интро/заставка);
    - последние 20 секунд видео: -0.25 (аутро/прощание);
    - speech_ratio < 0.30: -0.30;
    - longest_gap > 1.5 с: -0.15;
    - gap_ratio > 0.20: -0.15;
    - меньше 8 слов в окне: -0.50.

4.10. Итоговая оценка

    Каждый положительный признак нормировать по всем кандидатам в 0..1.
    Затем взвешенная сумма (веса — стартовые, вынести в config):

      score = 0.25 * speech
            + 0.25 * keywords
            + 0.15 * hooks
            + 0.10 * questions
            + 0.10 * numbers
            + 0.10 * emotion
            + 0.05 * self
            - penalties

    Если у всех кандидатов признак одинаковый (например, нет чисел),
    его вклад = 0, деления на ноль быть не должно.

    Оценку писать в лог в отладочном режиме, чтобы можно было понять выбор.

======================================================================
5. ВЫБОР ОКОН
======================================================================

1. Отсортировать кандидатов по score (по убыванию).
2. Жадно брать лучшие, пока не набрано HIGHLIGHTS_COUNT.
3. Пропускать окно, если оно пересекается с уже выбранным или ближе
   HIGHLIGHTS_MIN_GAP секунд (по умолчанию 4 с).
4. Финальный список отсортировать по времени начала — части должны идти
   по порядку видео, а не по оценке.
5. Если выбрано меньше 1 окна — откат на старую нарезку.

Количество:
    HIGHLIGHTS_COUNT = 10 по умолчанию.
    HIGHLIGHTS_COUNT = 0 — авто: round(длительность / CLIP_DURATION),
    но не меньше 1 и не больше 50.

Пример: видео 1 час, CLIP_DURATION 45 → авто даст ~50 (упрётся в потолок),
фиксированные 10 дадут 10 лучших моментов. По умолчанию — 10.

Показывать в подменю текущее состояние и короткое пояснение:

10. DEFINITION OF DONE
======================================================================

- В меню есть переключатель и количество клипов.
- Режим работает на YouTube и TikTok.
- Выбор моментов идёт только по субтитрам, без анализа звука.
- Whisper вызывается один раз на видео, а не на каждую часть.
- При выключении поведение полностью совпадает со старым.
- Все тесты из п. 9 проходят.
- README обновлён: новая возможность, настройки, как это работает,
  список тестов.
- В логе видно, какие моменты выбраны и почему (хотя бы кратко).
- Никаких новых зависимостей и сетевых вызовов.
